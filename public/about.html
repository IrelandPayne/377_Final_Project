About This Dashboard

The Global Economic Trends Dashboard is a web application that helps users explore economic data in a simple and visual way.

Purpose

Economic data can be difficult to understand when it is shown in large tables or complex reports. This dashboard turns global economic data into charts, statistics, and short summaries so users can understand trends more easily.

Data Source

This project uses data from the World Bank Indicators API. The data includes economic indicators such as GDP, inflation, unemployment, and life expectancy.

Target Users

This dashboard is designed for students, teachers, researchers, and anyone interested in comparing global economic trends across countries.

How It Was Built

The front end was built with HTML, CSS, and JavaScript. The backend uses Node.js and Express to request and clean data before sending it to the dashboard. Supabase was also used to provide database functionality and support backend storage.
